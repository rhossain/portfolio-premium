## Capture notes

Native website screenshots with the original interface, text and photography. Fonts and visible images were loaded before capture. The live demo banner was dismissed through its Close control. Mobile compositions use cream backgrounds, forest-green accents and simple frames; the screens preserve the native mobile layout.

The international map overview is used because selecting an individual residence produced missing map tiles. Both delivered map captures show loaded maps. The mobile map uses the site’s Show map control.

Development image 07 shows an available sample unit selected. The floor-plan image shows the default living-and-dining selection. Image 12 was captured using the site’s one-click Administrator demo account. No listings, leads or other business records were edited, and no enquiry was submitted. All property prices, inventory and sales-workspace records shown are demo content.

The ZIP includes images/, mobile/, this README, manifest.json and contact-sheet.jpg. The contact sheet is a review aid. No portfolio content entry, hosted storage or deployment was changed.
